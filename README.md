# 米饭复读机

一只只会喊「米饭呢」的蓝色大肥鱼。没有技术含量，只有嘴。

## 指令

| 指令 | 作用 |
| --- | --- |
| `/米饭` | 回一句米饭相关话术 |
| `/抽象` | 回一句抽象话术 |
| `/喂饭 <内容>` | 记一句自定义复读素材（内存态，重启即忘） |

## 配置

- `passive_enable`：被动复读开关，默认 **关**
- `passive_probability`：被动触发概率，默认 `0.05`
- `passive_keywords`：被动触发关键词，默认 `米饭 / 干饭 / 饿了`

## 注意

被动复读会看所有消息，开了可能变吵，慎用。
